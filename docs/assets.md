# Графика ФинДруг

Иконка приложения: предоставленный пользователем `FinDrug_512x512.png` (512×512), сохранён без изменений как `app/src/main/res/drawable-nodpi/findrug_app_icon.png`. Подключён в манифесте через `@mipmap/ic_launcher` для обычного и круглого значка. Адаптивная оболочка размещает квадрат в видимой области системной маски; исходный PNG не редактируется. Размеры слоёв: [Android AdaptiveIconDrawable](https://developer.android.com/reference/android/graphics/drawable/AdaptiveIconDrawable). По просьбе пользователя APK после добавления иконки не пересобирался.

Оригинальные ресурсы получены 26.09.2026 из пользовательского [Figma-файла «Игра»](https://www.figma.com/design/qadPdde1QXFGSHFlXg4On5/). Реестр — `figma-assets.json`. Изображения и SVG сохранены локально без перерисовки и обрезки исходников; приложение работает офлайн.

| Источник | Использование |
| --- | --- |
| 2058:326 | Приветствие: комната, машущий лисёнок, логотип, категории, реплика |
| 2039:1013 | Дом: комната, лежанка, показатели, монета, боковые действия, навигация |
| 2083:578, 2082:545 | Три цвета лисёнка и накладки одежды, аксессуаров, головных уборов |
| 2062:1397 | Категории бюджета и кнопки изменения суммы |

PNG: `app/src/main/res/drawable-nodpi/figma_*.png`. SVG: `app/src/main/res/raw/figma_*.svg`. Исходные viewBox, размеры и контуры SVG не изменяются; AndroidSVG 1.4 ([документация](https://bigbadaboom.github.io/androidsvg/)) масштабирует их при отображении. Нативные формы добавляют тени; SVG-фильтры могут отличаться от Figma.

Шрифты SN Pro, Days One, Playpen Sans получены из официального репозитория `google/fonts`, хранятся в `res/font`. Лицензии OFL — в `docs/licenses/`.

Ранее созданный ImageGen-атлас `reference_icons.png` используется только для домика и телескопа, которых нет в полученных макетах. Остальные основные значки заменены оригиналами Figma. Второстепенные товары без макетов используют emoji. Старые `reference_room.png` и `reference_fox.png` больше не используются новым интерфейсом.

Для выпуска остаются полный набор эмоциональных анимаций, авторские значки остальных товаров и звуковое оформление.
