# Учебный контент Android MVP

Актуально для 0.11.0. Контент хранится локально в `core/domain/src/main/kotlin/ru/findrug/domain/TaskCatalog.kt` и обновляется вместе с APK. Серверная публикация заданий не подключена.

| Тема | Задание | Действие и объяснение |
| --- | --- | --- |
| Бюджет | Нужно или хочу? | Распределить предметы; обязательные покупки нужны для заботы, желания можно отложить |
| Бюджет | Собери бюджет | Распределить ограниченную сумму, оставить на необходимое и накопления |
| Сбережения | Отложи на цель | Выбрать сумму, увидеть оставшийся бюджет и последствия |
| Сбережения | Путь к мечте | Сравнить регулярные накопления, расходование накоплений и откладывание остатка |
| Покупки | Найди выгоднее | Сравнить одинаковые упаковки и цену за единицу |
| Покупки | Уложись в бюджет | Собрать корзину с обязательной покупкой, не превысив доступную сумму |

Определение задания включает постоянный ID, название, тему, описание, награду и данные одного из четырёх типов взаимодействия. Короткие тренировки имеют отдельные определения с теми же ID; они не заменяют прохождение основного задания.

`TaskEvaluator` проверяет ответ по данным определения; интерфейс `TaskExercisePage` отображает тот же объект. Поэтому изменение цены, состава корзины или условия не требует правки двух независимых реализаций. `TaskDefinitions.validate` проверяет каталог при загрузке и в тестах. Достижения и количество пройденных заданий определяются по ID каталога.

[Инструкция добавления ситуации и правила наград](game-process-v9.md).

Дополнительный необязательный вопрос после первого решения задаётся через `ScenarioTask.reflection`. У него 2–3 варианта с пояснениями, без правильности и собственной награды. [Поведение и прогноз накоплений](learning-support-v11.md).
